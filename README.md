# E-Commerce Data Analysis Project

## Project Overview
An end-to-end data analysis project using a messy e-commerce dataset to investigate data quality issues, clean data, explore business trends, and develop actionable insights.

## Objectives
- Understand the dataset and identify data quality issues.
- Clean and validate data using Python and pandas.
- Perform exploratory data analysis (EDA).
- Answer business questions using SQL.
- Build an interactive Power BI dashboard.
- Document findings and business recommendations.

## Tools and Technologies
- Python
- pandas and NumPy
- Matplotlib and Seaborn
- SQL
- Excel
- Power BI
- Git and GitHub

## Project Workflow
1. Data Understanding
2. Data Cleaning
3. Exploratory Data Analysis
4. SQL Analysis
5. Power BI Dashboard
6. Insights and Recommendations
